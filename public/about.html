📖 System Architecture

About the Static Web Server

Understanding how Node.js and the Express framework collaborate to handle incoming HTTP requests, locate disk files, and serve them back over TCP/IP.

1️⃣

Project Initialization

The project starts by generating a standard package.json manifest using npm init -y, enabling seamless package management and script execution.

2️⃣

Express Framework

Express acts as the core HTTP request processing layer, abstracting low-level network sockets and providing powerful middleware pipelines.

3️⃣

Static Asset Pipeline

All client files—HTML documents, CSS style rules, browser scripts, and media—are organized within the public/ folder for automated delivery.

4️⃣

Route Dispatching

Supports both static path routing (e.g., /about.html) and clean routing (e.g., /about) via res.sendFile().

5️⃣

Environment Flexibility

Configured with process.env.PORT || 3000 to smoothly deploy across local development environments and cloud platforms like Render or AWS.

6️⃣

Low Resource Footprint

Minimalist dependencies and single-threaded event loop design ensure maximum throughput with minimal CPU and memory overhead.
